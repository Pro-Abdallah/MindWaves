# 🌊 MindWaves

> **MindWaves** is a graduation project dedicated to Bipolar Disorder Awareness. It is a cinematic, interactive web experience designed to explore and understand the journey of living with bipolar disorder through an ocean metaphor.

## 📖 Overview

MindWaves uses the powerful metaphor of the ocean to depict the highs and lows of bipolar disorder. Through interactive pages, cinematic videos, and personal stories, the project aims to foster empathy, understanding, and awareness.

## 🌟 Key Features & Pages

- **🎬 Cinematic Intro:** An immersive video sequence that sets the tone for the experience before entering the main site.
- **🌊 Understanding the Waves (OceanWorld):** An interactive 3D/2D node-based map where users can explore different "islands" representing various aspects and phases of bipolar disorder.
- **✉️ Messages From the Sea:** A collection of personal stories and letters sharing real experiences and thoughts.
- **🏄 Ride the Waves:** An interactive section detailing coping mechanisms and how individuals navigate their emotions.
- **🗣️ Inner Echo:** A reflection on the inner dialogue and thoughts accompanying the disorder.
- **⚓ Safe Harbor:** Resources, support systems, and professional help guidance for those in need.
- **🍾 A Bottle Returned:** Interactive feedback and reflections from the community.
- **🎞️ Official Trailer (Marfa'. Harbor):** A dedicated cinematic trailer summarizing the project's vision.
- **⛵ Why We Sail:** The "About Us" section introducing the team and the motivation behind this graduation project.

## 🛠️ Technology Stack

### Client (Frontend)
- **Framework:** [React 18](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Routing:** [React Router v7](https://reactrouter.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) for fluid, cinematic page transitions and UI animations.
- **Styling:** Custom CSS with a focus on immersive, dark-themed cinematic aesthetics (glassmorphism, gradients, and micro-animations).
- **Interactive Elements:** `react-pageflip` for realistic book-flipping effects.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher recommended)
- `npm` or `yarn`

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd MindWaves
   ```

2. **Install Client Dependencies:**
   ```bash
   cd client
   npm install
   ```

3. **Run the Client Development Server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173/` (or the port specified by Vite).

## 🎨 Design System

The application employs a carefully crafted design system:
- **Colors:** Deep ocean blues (`#020813`), glowing teals (`#38bdf8`), and atmospheric dark gradients.
- **Typography:** *Playfair Display* for cinematic, elegant headings, and *Inter* for clean, legible body text.
- **Visual Effects:** Scanlines, vignettes, and glowing orbs to simulate a deep-sea, cinematic environment.

**MindWaves (2026)** was developed as a graduation project with a core mission: **Bipolar Disorder Awareness**. The team aimed to create more than just an informational site—they built an experience that allows users to *feel* the metaphorical waves of the mind.
